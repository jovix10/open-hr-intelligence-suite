**Open-HR Intelligence** é uma suíte modular de ferramentas para Recursos Humanos, desenvolvida em Python e Streamlit. O objetivo é democratizar o acesso a tecnologias avançadas, como Inteligência Artificial e automação de dados, oferecendo uma alternativa *open-source*, gratuita e customizável para pequenas e médias empresas otimizarem seus processos de gestão de talentos.

Este projeto nasceu da necessidade de centralizar e simplificar tarefas operacionais do RH, permitindo que os profissionais foquem no que realmente importa: **as pessoas**.

---

## 🚀 Funcionalidades Atuais (v1.0.0)

Atualmente, a suíte conta com o módulo central de recrutamento:

### 🔍 Recrutador IA
Um analisador inteligente de currículos que utiliza Processamento de Linguagem Natural (PLN) para otimizar a triagem de candidatos.

* **Upload em Lote:** Suporte para upload de múltiplos currículos em formato PDF.
* **Análise de Compatibilidade:** Compara o conteúdo dos currículos com os requisitos da vaga inseridos pelo recrutador.
* **Score de Match:** Gera um ranking instantâneo dos candidatos mais aderentes à vaga, ordenados por compatibilidade.

### 🏢 Interface Moderna e Adaptável
* **Dashboard Visual:** Painel intuitivo com métricas-chave de recrutamento.
* **Modo Escuro/Claro:** Interface que respeita automaticamente a preferência do sistema operacional.

## 📦 Como Instalar e Rodar Localmente

**Pré-requisitos:** Python 3.12+ instalado.

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/jovix10/open-hr-intelligence.git](https://github.com/jovix10/open-hr-intelligence.git)
    cd open-hr-intelligence
    ```

2.  **Crie e ative um ambiente virtual:**
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate
    ```

3.  **Instale as dependências:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Execute a aplicação:**
    ```bash
    streamlit run main.py
    ```
